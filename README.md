# 🩺 MedMinder
**Remote Elderly Care & Monitoring System**

MedMinder is a comprehensive, responsive web application designed to bridge the communication and monitoring gap between elderly patients and their medical care teams. It provides real-time health tracking, medication reminders, and secure communication to ensure continuous and effective elderly care.

🔗 **Live Demo:** [med-minder-orcin.vercel.app](https://med-minder-orcin.vercel.app)

---

## ✨ Features

### 👤 Patient Portal
* **Health Tracking:** Log vital signs (Heart Rate, Blood Pressure, Oxygen, Glucose, Temperature, Weight) with automatic critical status detection.
* **Medication Adherence:** Visual adherence tracking and real-time interactive alerts for scheduled medications.
* **SOS Emergency:** Instant one-click SOS alerts sent to the assigned care team and emergency contacts.
* **Medical Profile:** Securely manage personal details, blood type, allergies, and chronic conditions.

### 👨‍⚕️ Doctor Portal
* **Patient Directory:** Search, connect with, and supervise multiple patients.
* **Analytics Dashboard:** Monitor patient adherence, prescription rates, and status distributions via dynamic charts.
* **Prescription Management:** Assign new medications with exact hour/minute scheduling directly to a patient's profile.
* **Full Medical History:** Access comprehensive graphical and tabular data of patient vitals and past alerts.

### 🤝 Caregiver Access
* **Active Alerts:** Real-time monitoring of missed medications and critical vital signs.
* **Adherence Overview:** Track overall task completion and medication adherence for supervised patients.

### 🔧 Core System Features
* **Role-Based Authentication:** Distinct interfaces and permissions for Patients, Doctors, and Caregivers.
* **Secure Messaging:** Built-in chat system for direct communication between the care team and patients.
* **Interactive UI:** Smooth transitions, responsive mobile-friendly design, and a dedicated Dark/Light mode toggle.
* **Local Data Persistence:** Utilizes browser `localStorage` to simulate a real-time database securely.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Icons:** [FontAwesome 6](https://fontawesome.com/)
* **Data Visualization:** [Chart.js](https://www.chartjs.org/)
* **Deployment:** Vercel

## 🚀 Getting Started

Since the application uses local storage for data simulation, no backend setup is required for local development.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/medminder.git](https://github.com/your-username/medminder.git)
   ```
2. **Navigate to the project folder:**
   ```bash
   cd medminder
   ```
3. **Run the application:**
   Simply open the `index.html` file in any modern web browser.
